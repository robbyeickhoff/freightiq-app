# Grand Junction — Downtown / The Hole

## Purpose

Document confirmed operational routing knowledge for the Downtown / The Hole
parent zone in the Grand Junction Valley.

Downtown / The Hole is a dense, independent delivery territory. A Grand
Junction trailer is normally assigned to one parent zone, so this territory is
not one step in a daily sequence through the other Grand Junction zones.

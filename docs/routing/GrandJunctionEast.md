# Grand Junction — East

## Purpose

Document confirmed operational routing knowledge for the East parent zone in
the Grand Junction Valley.

East is a dense, independent delivery territory. A Grand Junction trailer is
normally assigned to one parent zone, so East is not one step in a daily
sequence through the other Grand Junction zones.

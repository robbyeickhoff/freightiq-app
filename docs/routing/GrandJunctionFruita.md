# Grand Junction — Fruita

## Purpose

Document confirmed operational routing knowledge for the Fruita parent zone in
the Grand Junction Valley.

Fruita is a dense, independent delivery territory. A Grand Junction trailer is
normally assigned to one parent zone, so Fruita is not one step in a daily
sequence through the other Grand Junction zones.
